# Coding Standards

## File Index

This file records coding and styling conventions for the project.
It emphasizes preserving existing class names where practical.
It limits unnecessary business-logic changes.
It requires accessibility semantics and responsive styling to be preserved.
It also points styling changes toward shared CSS custom properties.

## Content

Date: 2026-03-18

General:
- Keep existing class names when possible.
- Avoid unnecessary changes to business logic.
- Preserve accessibility semantics and focus styles.

Styling:
- Use CSS custom properties defined in index.css.
- Maintain responsive layout for desktop and mobile.
