# Tech Stack

## Core Technologies
- **Language**: JavaScript (ES2020+) for broad browser support.
- **Markup/Styles**: HTML5 and CSS3.

## Libraries & Dependencies
- **None**: POC targets zero runtime dependencies.

## Development Tools
- **Optional**: Any static file server for local testing (e.g., `python -m http.server`).

## Rationale
A dependency-free stack is fastest to iterate for a simple static game and aligns with S3 hosting.
