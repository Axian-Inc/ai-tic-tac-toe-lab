# Testing Strategy

## Test Categories
- **Manual Tests**: Primary for POC; verify gameplay, AI behavior, and UI updates.

## Priorities
1. Win/tie detection correctness.
2. AI move legality and turn order.
3. UI win highlight and celebration.

## What NOT to Test
- Cross-browser matrix beyond latest Chromium for POC.

## Test Standards
- Use a simple manual checklist during validation.

## Running Tests
No automated tests in this POC.
