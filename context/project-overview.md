# Project Overview

## Purpose
Create a simple single-player Tic-Tac-Toe web app with AI opponents, suitable for static hosting in an S3 bucket.

## Goals
- Deliver a playable 3x3 Tic-Tac-Toe experience vs AI in a static web page.
- Provide at least two distinct AI opponent styles (random and optimal).
- Keep the UX simple with start/restart, win highlighting, and a celebration effect.

## Scope
**In scope:**
- One-page web app (HTML/CSS/JS) hosted statically.
- Two AI styles: random and optimal (minimax).
- Visual win highlight and celebration on victory (X/O confetti).

**Out of scope:**
- Multiplayer or networked play.
- User accounts, persistence, or analytics.
- Complex UI/animations beyond simple celebration.

## Stakeholders
- **Product owner**: User

## Key Assumptions
- Static hosting on S3 with no backend or server-side logic.
- Vanilla web stack is acceptable unless later requested otherwise.
