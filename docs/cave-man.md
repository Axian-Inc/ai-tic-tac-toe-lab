# Cave Man User Guide

## Big Picture
You play rock game on magic square.

Square have 9 holes.

You put mark.
Other player put mark.

Make 3 in line.
You win.

No 3 in line and board full.
Game draw.

## Start Game
1. Open game.
2. Put name in name box.
3. Pick fight type.
4. Hit `Start game`.

Name must:

- use letter or number
- be 24 signs or less

## Pick Fight Type
### `Player vs Player`
Two humans bonk on same board.

### `Player vs CPU`
You fight machine brain.
Machine brain make move right away when machine turn comes.

## During Game
- Game tell whose turn now.
- Game tell who controls mark.
- Empty glowing hole means move can go there.
- Full hole means no move there.
- Locked hole means wait. No touch.
- Piece go down with nice thud sound.

## Win, Lose, Draw
### If you win
- game celebrate
- confetti fly
- win sound play

### If you lose to CPU
- lose sound play
- game say `Try again`

### If nobody wins
- game say `Draw`

## Buttons
### `New game`
Start fresh fight in same mode.

### `Mode`
Change fight type.
Old game go away.
New game begin.

### `Quit game`
Leave board.
Go back to start screen.

### `Rematch`
After CPU fight ends, you can fight CPU again.

## Important Cave Truth
- Game pick first player at random.
- In CPU fight, machine may go first.
- CPU always make legal move.
- Game not save after you leave.
